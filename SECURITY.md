# Security Policy

## Supported version

Security fixes are applied to the latest release and the `main` branch.

## Report a vulnerability

Use GitHub's private vulnerability reporting flow:

<https://github.com/iicmaster/artifact-sftp/security/advisories/new>

Do not open a public issue with exploit details, credentials, host keys,
private artifact URLs, or configuration contents. If private reporting is
unavailable, contact the repository owner through an established private
channel and include only enough information to arrange a secure handoff.

If a real credential was exposed, rotate or revoke it immediately before
reporting it.
