Security Invariants (กฎความปลอดภัยขั้นสูงสุด)

1. Never draw a secret: ไม่เปิดเผย private keys, passwords หรือ CF Access tokens ลงใน diagram หรือ output
2. No viewer URL fetches: AI Agent อ่านไฟล์กลับผ่าน local read-back path เท่านั้น ป้องกันการชน Cloudflare Zero Trust
3. Subprocess PATH Isolation: ตัด adapter venv ออกจาก PATH เพื่อให้ child scripts เรียกใช้ system python3-paramiko ได้ถูกต้อง

🔄 Runtime Flow (กระบวนการทำงานเมื่อเรียก Publish)

1

AI Host Discovery (Claude Code / Codex / Agent Plugins)

Host โหลด .mcp.json หรือ mcp.json และเริ่มรัน stdio process bin/artifact-sftp-mcp

2

Tool Invocation (artifact_sftp.publish)

ส่ง parameters เช่น slug, source_path, และ confirm=true เข้าสู่ Server

3

Subprocess PATH Sanitization & Stamping

SubprocessRunner ทำความสะอาด PATH ป้องกัน adapter venv บัง system tools จากนั้น stamp font Sarabun และ metadata

4

Local Archive & Remote Upload

บันทึก local copy ลงใน docs/artifacts/... ก่อน แล้วจึงอัปโหลดขึ้น SFTP ผ่าน sftp_helper.py

5

Safe Read-Back Return

ส่ง path ของ local archive กลับมาให้ Agent ตรวจสอบผลงานได้ทันทีโดยไม่ต้อง fetch ผ่าน web
