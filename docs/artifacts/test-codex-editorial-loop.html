03DEEP DIVE / รายละเอียดเชิงลึก
Stage contracts, evidence, and memory outputsเปิดรายละเอียดการส่งต่อของแต่ละ Stage

แต่ละ Stage มี Input และหลักฐานที่ชัดเจน เมื่อระบบจบ Cycle แล้ว Shared Memory จะเก็บเฉพาะ Pattern และกฎที่ผ่านการพิสูจน์ เพื่อให้การปรับปรุงรอบต่อไปตรวจสอบย้อนกลับได้

Stage Input → Action Evidence / Memory output
01 · Build / Inspect Pattern + งานที่ต้องทำ → สร้างโค้ดและวิเคราะห์สถาปัตยกรรม Candidate diff, architecture notes
02 · Attack / Gate Candidate → ตรวจจุดบกพร่องด้วย CRAP score และ mutation tests Audit findings, mutation result, gate decision
03 · Prove / Verify Build ที่ผ่าน Gate → รัน regression suite และ security scan 100% regression pass, scan report, runtime evidence
04 · Learn / Evolve หลักฐาน + Pitfalls → สกัดกฎ ปรับ Skill และเขียนกลับ New Pattern, updated rule, next-cycle guidance
