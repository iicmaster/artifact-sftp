1. ปลอดภัยจากการ Shell Injection (Quoted Heredoc)

ห้ามใช้คำสั่งแบบ string interpolation เช่น printf '%s' เพราะหาก Mermaid มีเครื่องหมาย apostrophe (เช่น User's browser) จะทำให้เชลล์เออเรอร์ ต้องส่งผ่าน Quoted Heredoc cat <<'EOF' | npx ondine เสมอ

2. คง Monospace Font Metrics (--ondine-font)

Ondine คำนวณความกว้างกล่องในภาษา Rust ไว้ที่ 0.6em ต่อตัวอักษร จึงต้องคงชุดฟอนต์ Monospace เอาไว้ เพื่อไม่ให้ตัวอักษรล้นกล่องหรือทับเส้นเชื่อม

3. บังคับใส่ ID Namespace ก่อนส่ง Audit

เพื่อปฏิบัติตามกฎ skills/artifact-audit/SKILL.md:82 ทรัพยากร SVG (เช่น marker, clipPath, gradient) ต้องถูกใส่ prefix ป้องกันการชนกัน เช่น id="dia1-..." เสมอ

4. Option 4 Invariant: ปราศจาก Client JS

ผลลัพธ์จาก Ondine เป็น Static Inline SVG แท้ๆ ห้ามใช้ script runtime หรือดึงข้อมูลจาก endpoint ภายนอก (https://ondine.sh) ในตัว artifact ที่นำไปเผยแพร่
