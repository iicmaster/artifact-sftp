# Artifact SFTP

*ฉบับหลักคือ [README.md](README.md) — ขั้นตอนติดตั้ง คอนฟิก MCP และโมเดลความปลอดภัยอยู่ที่นั่น*

คุณมีไฟล์ HTML หนึ่งไฟล์ในเครื่อง — มันพาไฟล์นั้นไปอยู่บนเว็บของคุณเอง ที่ลิงก์ซึ่งไม่เปลี่ยน
และมันไม่ได้ทำแค่นั้น มันมีชุดสกิลสำหรับ **ทำให้เอกสารดีพอที่จะเผยแพร่** มาให้ด้วย

> **สิ่งที่มันไม่ใช่:** มันไม่ใช่บริการโฮสต์ มันไม่มีเซิร์ฟเวอร์ให้คุณ
> คุณต้องมีบัญชี SFTP กับเว็บเซิร์ฟเวอร์ของตัวเองอยู่แล้ว
> — มันคือ *คนส่งของ* ไม่ใช่ *โกดัง*
> ใน repo นี้ไม่มีรหัสผ่านหรือคีย์ใด ๆ และไม่ได้ให้สิทธิ์เข้าถึงเครื่องของผู้ดูแล

## วงจรที่มันครอบคลุม

ตัวส่งไฟล์ทั่วไปทำแค่สองแถวล่าง ปลั๊กอินนี้ทำครบทุกแถว และแต่ละแถวเรียกใช้เดี่ยว ๆ ได้

| ขั้น | เกิดอะไรขึ้น | ใครทำ |
|---|---|---|
| **เขียน** | คุณร่างไฟล์เดียวที่จบในตัวเอง | คุณ หรือผู้ช่วย |
| **ขัดสำนวน** | วลีแปลหุ่นยนต์กับประโยคถูกกระทำที่ยืดยาดถูกเอาออก ปรับระดับภาษาให้ตรงคนอ่าน | `thai-prose-craft` |
| **จัดโครง** | สรุปขึ้นก่อน สถาปัตยกรรมตรงกลาง รายละเอียดลึกไว้ท้าย | `artifact-curator` |
| **วาด** | ไดอะแกรมที่ผ่านการตรวจไวยากรณ์ หรือภาพที่เล็กที่สุดที่ทำให้เข้าใจ | `visual-illustrator`, `show-me` |
| **ตรวจ** | ห้ามิติ — สำนวน ไวยากรณ์ไดอะแกรม โครงสร้าง ลิงก์ ความลับ · เจอคีย์หลุดหรือลิงก์ตายแล้วหยุด | `artifact-audit` |
| **ส่ง** | เก็บสำเนาในเครื่องก่อน แล้วอัปโหลด แล้วเทียบไบต์ แล้วลองเปิดแบบไม่ล็อกอิน | `artifact_sftp.publish` |
| **เก็บ** | ทุกเวอร์ชันอยู่ใต้ `docs/artifacts/` และตามหาของค้างได้ทีหลัง | `artifact_sftp.list`, `artifact-groom` |

## เส้นทางของไฟล์หนึ่งไฟล์

```text
1  คุณเขียนไฟล์ .html หนึ่งไฟล์
       CSS กับ JavaScript อยู่ข้างในหมด ไม่ดึงของจากที่อื่น
            ↓
2  สแกนหาความลับที่หลุดมา  ← ก่อนอย่างอื่นทั้งหมด
       เจอรูปแบบที่เหมือนคีย์หรือรหัสผ่าน → ออกด้วยรหัส 4 ทันที
       ยังไม่มีสำเนาถูกสร้าง ยังไม่มีอะไรถูกส่ง
            ↓
3  เก็บสำเนาไว้ในเครื่อง  ← ก่อนอัปโหลด
       docs/artifacts/<tool>/<visibility>/<slug>/
       ทั้งไฟล์ปัจจุบันและสำเนาที่ปั๊มเวลาไว้ อัปโหลดล้มทีหลังของยังอยู่ครบ
            ↓
4  อัปโหลดผ่าน SFTP
       ตรวจลายนิ้วมือเซิร์ฟเวอร์ก่อนคุย เจอเครื่องแปลกปลอมแล้วไม่ยอมส่ง
            ↓
5  พิสูจน์ว่าคนนอกเปิดไม่ได้
       ลองเปิดแบบไม่ล็อกอิน ถ้าเปิดได้ = หลุด ถือว่าล้มเหลว
       ส่วนการเทียบ SHA-256 กับไบต์บนเซิร์ฟเวอร์ทำได้เฉพาะตอนมี
       Cloudflare service token ในคอนฟิก ถ้าไม่มี ผลลัพธ์จะบอกว่า
       not_independently_byte_verified ตรง ๆ ไม่แอบเคลมว่าเทียบแล้ว
```

## สามอย่างที่ `scp` ธรรมดาไม่ทำให้

- **ทับแล้วของเก่าไม่หาย** — ทุกครั้งที่ส่ง มันเก็บสำเนาแยกพร้อมเลขเวอร์ชันและเวลาไว้ข้าง ๆ ตัวปัจจุบัน
- **เงียบไว้ก่อนเป็นค่าเริ่มต้น** — `private` คือค่าตั้งต้น จะทำให้เป็นสาธารณะต้องยืนยันเพิ่มอีกชั้นหนึ่งโดยเฉพาะ
- **ไม่เชื่อว่า "ส่งแล้ว" แปลว่าสำเร็จ** — ของ `private` มันลองเปิดแบบไม่ล็อกอินเพื่อพิสูจน์ว่าคนนอกอ่านไม่ได้ และรายงานตรง ๆ ว่าเทียบไบต์ได้หรือไม่ได้ ไม่กลบด้วยคำว่าสำเร็จ

## ลิงก์ที่ได้ ประกอบด้วยอะไร

```text
https://เว็บของคุณ/claude/private/my-report/
                   ▲       ▲       ▲
                   │       │       └─ slug ชื่อที่คุณตั้ง
                   │       └───────── visibility: private หรือ public
                   └───────────────── tool: codex, openclaw หรือ claude
```

- **tool** — ผู้ช่วยตัวไหนเป็นคนส่ง แยกกันคนละเส้นทาง
- **visibility** — `private` กับ `public` อยู่คนละโฟลเดอร์ ไม่ปนกัน
- **slug** — ขึ้นต้นด้วยตัวพิมพ์เล็กหรือตัวเลข ตามด้วยตัวพิมพ์เล็ก ตัวเลข หรือขีดกลาง รวมไม่เกิน 63 ตัว

## สกิลทั้งสิบตัว

สามตัวขนไบต์ · ห้าตัวทำให้เอกสารดี · สองตัวเฝ้าประตู

### ส่งของ

| สกิล | ทำอะไร |
|---|---|
| `artifact-sftp` | เผยแพร่ HTML artifact ผ่าน MCP adapter |
| `artifact-sftp-read` | อ่านสำเนาในเครื่องแบบออฟไลน์ ไม่ไปดึงจากลิงก์ |
| `artifact-sftp-setup` | ตรวจความพร้อมและบอกขอบเขตของคอนฟิก ไม่รับรหัสผ่าน |

### ทำให้เอกสารดี

| สกิล | ทำอะไร |
|---|---|
| `thai-prose-craft` | บรรณาธิการภาษาไทย ตัดวลีแปลหุ่นยนต์และประโยคถูกกระทำที่ยืดยาด ปรับระดับภาษาให้ตรงคนอ่าน |
| `artifact-curator` | สถาปนิกโครงเอกสาร สรุปสามชั้น กล่องแจ้งเตือนแบบ GitHub และตารางเปรียบเทียบแทนลิสต์ยาว ๆ |
| `visual-illustrator` | Mermaid ที่ไวยากรณ์ไม่พัง บังคับใส่เครื่องหมายคำพูดในป้ายกำกับ ตรวจชนิดแผนภาพ และคุมโทนสี |
| `doc-synchronizer` | ตรวจว่าเอกสารยังตรงกับโค้ดจริงไหม README, SKILL.md, manifest, ลิงก์, anchor และแฟล็ก CLI |
| `show-me` | อธิบายด้วยภาพที่เห็นแล้วเข้าใจทันที เอาความเข้าใจขึ้นก่อน เผยแพร่เป็นหน้า HTML พร้อมสรุปในแชท (หรือแสดงในแชทอย่างเดียวด้วย `--inline`) |

### เฝ้าประตูและดูแลระยะยาว

| สกิล | ทำอะไร |
|---|---|
| `artifact-audit` | ด่านก่อนเผยแพร่ ให้คะแนนห้ามิติแล้วตัดสิน PASS / WARN / BLOCK · BLOCK คือหยุด แล้วส่งเอกสารไปหาสกิลที่ซ่อมได้ · `artifact-sftp` กับ `artifact-groom` ต้องเรียกมันก่อนเสมอ |
| `artifact-groom` | ไล่ตรวจ artifact ทั้งโปรเจกต์ แยกว่าอันไหนสด อันไหนเก่า อันไหนกำพร้า แล้วอัปเดตหรือถอนออกอย่างปลอดภัย |

## เครื่องมือที่เรียกผ่าน MCP มีหกตัว

| เครื่องมือ | ทำอะไร |
|---|---|
| `artifact_sftp.setup_status` | พร้อมส่งหรือยัง คอนฟิกครบไหม ต่อเครื่องปลายทางติดไหม |
| `artifact_sftp.setup` | บอกว่าต้องเตรียมอะไรเพิ่ม ไม่รับรหัสผ่าน ไม่รันตัวติดตั้งให้ |
| `artifact_sftp.publish` | ส่งไฟล์ขึ้น ต้องสั่ง `confirm` เสมอ จะให้เป็นสาธารณะต้องสั่ง `confirm_public` เพิ่ม |
| `artifact_sftp.unpublish` | เอาลงจากเซิร์ฟเวอร์ สำเนาในเครื่องยังอยู่เสมอ |
| `artifact_sftp.read` | อ่านสำเนาในเครื่อง |
| `artifact_sftp.list` | ดูว่าเคยส่งอะไรไปแล้วบ้าง และมีร่างอะไรค้างอยู่ |

> **ทำไมลิงก์ `private` ถึงอ่านไม่ได้:** มันเป็นลิงก์สำหรับ *คนเปิดดู* ที่มีด่านกั้นอยู่ข้างหน้า
> ไม่ใช่ที่อยู่สำหรับให้โปรแกรมไปดึงข้อมูล อยากอ่านเนื้อหาให้ใช้ `artifact_sftp.read` กับสำเนาในเครื่องแทน

> **ผู้ช่วย AI ต้องเรียกผ่านหกตัวนี้เท่านั้น** ห้ามไปเรียกสคริปต์ข้างในตรง ๆ
> ห้ามหาทางอื่นส่งแทน และห้ามแตะคอนฟิกหรือรับความลับผ่านแชท
